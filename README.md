# Escápate MX — Tours desde Tecámac

Landing page para una agencia de escapadas de fin de semana.

## Stack
- HTML5
- CSS3
- JavaScript vanilla
- Compatible con GitHub Pages

## Antes de publicar
1. Abre `script.js`.
2. Cambia `WHATSAPP_NUMBER` por el número real del negocio.
3. Sustituye fechas, precios e imágenes de referencia por datos reales.
4. Revisa hotel, transporte y condiciones antes de publicar.

## Flujo de reserva
El usuario selecciona un tour → pulsa Reservar → se abre WhatsApp con un mensaje prellenado → disponibilidad, precio final, pago y detalles se confirman por WhatsApp.

## Publicación
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
